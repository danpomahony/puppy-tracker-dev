# Puppy tracker app

The phone app: Vite, React and TypeScript. See the [project README](../README.md) for what it is and how to run it.

```sh
npm install
npm run dev             # http://localhost:5173
npm run lint
npm test                # unit tests (Vitest), run in two timezones
npm run build           # also the type check (tsc -b)
```
